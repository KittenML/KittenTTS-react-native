# Tutorials

These are longer, copy-paste-friendly walkthroughs. They are meant for building
a small app, not for looking up one API option.

## Simple TTS App

Build a screen with a text box and a Speak button, with Kitten TTS 2 Nano.

- [macOS](simple-tts/mac.md)
- [Windows](simple-tts/windows.md)

## Reader App

Add KittenTTS to a reader-style app with streamed generation and word
highlighting. It uses the Kitten TTS 0.8 models, for their cache helpers and
per-sentence word timings, and ends with what changes for Kitten TTS 2 Nano.

- [macOS](epub-reader/mac.md)
- [Windows](epub-reader/windows.md)
